## ➕ Adding a New DAO

1. Fork this repository.
2. Create a directory under `config/<network>/<dao-slug>/`.
3. Add a `Structa.toml` with your DAO’s metadata and addresses.
4. Open a pull request with a meaningful description.

For examples, refer to `config/mainnet/exampledao/Structa.toml`.
